# 验证检查清单 — 设置报告

规则随时间累积。每次 workflow-changelog 运行**必须**以指定深度执行**所有**规则。当发现现有规则应该捕获到（但该规则不存在或深度不够）的新型漂移时，在此追加新规则。

## 深度级别

| 深度 | 含义 | 示例 |
|-------|---------|---------|
| `存在` | 检查部分/表格/文件是否存在 | "报告是否有沙箱设置表格？" |
| `存在检查` | 检查特定项目是否存在或缺失 | "钩子事件表格中是否有 `ConfigChange` 事件？" |
| `内容匹配` | 将实际值与来源逐字比较 | "`model` 设置描述是否与官方文档匹配？" |
| `字段级别` | 验证每个单独的字段是否都被涵盖 | "官方文档中的每个设置键是否出现在正确的表格中？" |
| `跨文件` | 相同值必须在多个文件间匹配 | "CLAUDE.md 的钩子部分是否与报告的钩子事件匹配？" |
