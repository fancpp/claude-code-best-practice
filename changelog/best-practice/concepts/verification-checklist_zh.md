# 验证检查清单 — README 概念部分

用于验证概念表格准确性的规则。每次工作流运行时检查每条规则。

## 规则

### 1. 外部 URL 有效性
- **类别**：URL 准确性
- **检查内容**：概念表格中的每个外部 URL（文档链接）返回有效页面
- **深度**：获取每个 URL 并确认其加载了预期页面（不是重定向到错误页面）
- **对比来源**：`https://code.claude.com/docs/llms.txt` 用于规范 URL 列表
- **添加日期**：2026-03-02
- **来源**：发现权限 URL `/iam` 重定向到认证页面而非权限页面

### 2. 锚点片段有效性
- **类别**：URL 准确性
- **检查内容**：任何带有锚点片段（`#section-name`）的 URL 匹配目标页面上的实际标题
- **深度**：获取页面并验证标题以预期锚点存在
- **对比来源**：获取的页面内容
- **添加日期**：2026-03-02
- **来源**：规则锚点 `#modular-rules-with-clauderules` 已过时；部分已重命名为 `#organize-rules-with-clauderules`

### 3. 缺少的文档页面
- **类别**：缺少概念
- **检查内容**：官方文档索引（`llms.txt`）中代表面向用户功能的每个页面在概念表格中都有对应的行
- **深度**：将完整文档索引与概念表格条目进行比较
- **对比来源**：`https://code.claude.com/docs/llms.txt`
- **添加日期**：2026-03-02
- **来源**：发现多个缺少的概念（代理团队、键绑定、模型配置等）

### 4. 本地徽章链接有效性
- **类别**：徽章准确性
- **检查内容**：概念表格中的每个徽章目标路径（`best-practice/*.md`、`implementation/*.md`、`.claude/*/`）指向存在的文件或目录
- **深度**：使用 Read/Glob 验证文件存在性
- **对比来源**：本地文件系统
- **添加日期**：2026-03-02
- **来源**：初始检查清单创建

### 5. 描述时效性
- **类别**：描述准确性
- **检查内容**：每个概念的描述准确反映当前官方文档的描述
- **深度**：将 README 描述与官方页面的 meta 描述或第一段进行比较
- **对比来源**：官方文档页面内容
- **添加日期**：2026-03-02
- **来源**：记忆描述缺少自动记忆；MCP 服务器位置缺少 `.mcp.json`

### 6. TIPS 部分 URL 一致性
- **类别**：URL 准确性
- **检查内容**：当概念或热点表格中的 URL 更新时，还要检查 TIPS 部分是否有相同的过时 URL
- **深度**：搜索 TIPS 部分（第 125–267 行）中每个在概念/热点表格中被标记的 URL
- **对比来源**：llms.txt 站点地图 + 概念表格 URL
- **添加日期**：2026-04-16
- **来源**：`web-scheduled-tasks` URL 在热点表格中已修复（2026-04-14），但相同的过时 URL 仍存在于 TIPS（第 223 行）中

### 7. Beta 徽章时效性
- **类别**：徽章准确性
- **检查内容**：热点表格中标记为 `![beta](!/tags/beta.svg)` 的概念在其官方文档页面中应仍被标记为 beta / 研究预览（标题横幅、"研究预览"文案或环境变量门控）
- **深度**：获取每个上游页面并检查是否有明确的 beta/预览/实验性措辞；如果不存在，则 README 徽章可能已过时
- **对比来源**：官方文档页面横幅文本 + GA 标记文案
- **添加日期**：2026-04-26
- **来源**：Workflow-concepts-agent 标记 Routines、无闪烁模式、计算机使用和代码审查带有 README beta 徽章，而其文档页面看起来像 GA（置信度 0.6）— 这种漂移类型未被现有的描述时效性规则覆盖
